## Key Design Decisions

1. **Windows-LAPS-only:** All code uses ms-LAPS-* attributes; never legacy ms-Mcs-AdmPwd
2. **Direct LAPS cmdlet calls:** Set-LapsADComputerSelfPermission, Set-LapsADReadPasswordPermission, Set-LapsADResetPasswordPermission
3. **-DomainController on all calls:** Threaded through all 3 Set-LapsAD* invocations
4. **Principal format:** "NetBIOS\sAMAccountName" resolved at plan time via Get-ADGroup
5. **Tier 0 Admins root delegation:** New OU "Tier Model Administration" assigned SELF permission so Tier0Admins own LAPS across all PAW tiers
6. **Central schema:** No per-feature schema files; tiermodel.schema.json aligned instead (T002 dropped)
7. **Action model:** 3 actions per delegation (Self+Read+Reset); 7 OUs × 3 = 21 total when fresh
8. **Phase integration:** Phase 10 in full-deployment orchestration (after Phase 9, dMSA)
9. **Idempotency detection:** Find-LapsADExtendedRights for Read/Reset; Get-Acl "AD:$ouDn" for SELF (corrects PS7 IsInherited mismatch)
