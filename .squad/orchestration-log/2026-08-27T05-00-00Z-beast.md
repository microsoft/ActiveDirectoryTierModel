## Design Principles

- **Plan-based API**: Mirrors WinLaps pattern (Fd planners → New-* executors)
- **SDDL invariant**: Member_of_any (OR) only — AND logic is a documented lockout failure mode
- **1:1 mapping**: Each silo → one policy; all three account classes use the same policy
- **Audit mode**: All objects created with Enforce=$false; enforcement is a separate gated lifecycle step
- **Protected**: All objects created with ProtectedFromAccidentalDeletion=$true
- **Idempotent**: Pre-checks before Grant and Set operations; membership re-evaluated on every run
- **RID-500 exemption**: Resolved at runtime to handle renamed built-in administrator accounts
