## Learnings

1. **Bug A Pattern:** Get-Acl "AD:$dn" returns definitive IsInherited=True/False in PS7. Find-LapsADExtendedRights is insufficient for SELF detection (never surfaces SELF in ExtendedRightHolders). Always pre-compute LAPS schema GUIDs once before the detection loop, then filter ACEs by non-inherited + LAPS GUID membership.

2. **Bug B Pattern:** Mixed Findings schemas require property-existence guards under StrictMode -Version Latest. When multiple audit cmdlets feed a consolidated reporter, validate `$_.PSObject.Properties.Name -contains 'PropertyName'` before accessing that property. Do NOT assume all Findings objects have the same shape.

3. **Decryptor Output Shape:** WinLaps Decryptor findings use {GpoName, Expected, Actual, Status} (not the ACL {Type, ResourceType, ...} shape). FullDeployment wrapper tolerates this because it only uses Summary.* fields for aggregation; per-finding detail display relies on findings[].Type='Drift', which neither WinLaps cmdlet emits, so per-item detail is correctly absent.

4. **Lab Stability:** Deployed + compliant state persists across audit runs. Idempotency (Applied 0, Converged True on 2nd run) confirms both deploy and audit are correctly detecting existing state.
