## Learnings — 2026-09-04 (second turn, BUG-014 completion)

- **The real acceptance test is the merged runtime object, not individual segment files.** Individual config files pass through transformations in Get-TierModelConfig (renaming keys, injecting runtime metadata). Validate the OUTPUT of the function, not the input files.
- **NJsonSchema (Test-Json) reports errors from ALL branches of a failing oneOf, even branches that "almost" passed.** When oneOf [null, array] fails because the null branch gets an array value, the error "array but should be null" appears even if the array branch passed.
